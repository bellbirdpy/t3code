# Bellbird brand asset

`logo-onedrive.png` is the reviewed Bellbird bird mark sourced from the company's
OneDrive folder `Comercial y Marketing/Marca/Histórico` on 2026-08-26.

The production application variants are derived from this source without changing
the artwork. Existing upstream-compatible output filenames under `assets/prod/`
are intentionally retained so build and release tooling does not need a namespace
migration.
